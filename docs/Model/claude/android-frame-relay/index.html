    一句话记住

    七个字串起一整帧，点击跳到对应章节。

    1. UI 只写清单：invalidate 只做标记，onDraw 只把命令录进 DisplayList。
    2. RT 下单，GPU 干活：命令提交后 CPU 就走，像素由 GPU 异步写入。
    3. 交出去的是 buffer + fence：不是“画好的图”，而是“图 + 何时画完的凭证”。
    4. SF 按自己的节拍合成：latch 只是选定，present 只是提交，下一次硬件 VSync 才开始扫描。
    5. 旧 buffer 要等灯亮才能复用：release fence 证明显示硬件读完了。

    怎么看这页

    • 舞台：三条色带是三个边界：蓝色应用进程、橙色 SurfaceFlinger 进程、紫色硬件 / HAL（不是一个进程）。
    • 红色圆点 F 落在当前执行者上；红色流动虚线是本步的交接路径；黑色波纹是 VSync 脉冲。
    • 粗框 = 当前步骤；黑色虚线框 = 同一时刻也在运行；黄色斜纹 = 正在阻塞等待。
    • 底部四个指示灯：交接物、acquire fence、release fence、屏幕。灰 = 尚无，黄 = 未 signal，绿 = 已 signal。
