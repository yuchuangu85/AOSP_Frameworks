RemoteViews

传递的是“如何构造和修改 View”的描述，
不是另一进程里的 View 对象。

提供方记录 layoutId 与 Action，Parcel/Binder 携带协议数据，宿主进程 inflate 出真实 View，再按 viewId 执行被允许的方法。AppWidget → Launcher 是它的一条宿主路径。
